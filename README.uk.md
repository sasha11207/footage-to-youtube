# Footage to YouTube

[English](README.md) · **Українська**

> Перетворіть власні відео на довгі ролики для YouTube (і Shorts) за допомогою Claude Code: питання, короткі тестові фрагменти, потім рендер. Mac і Windows.

Ви спілкуєтеся з **Claude Code** звичайною мовою. Claude ставить прості запитання (ви відповідаєте
цифрою), переглядає папку з вашими відео, робить **короткі тестові фрагменти зі звуком**, щоб ви їх
перевірили, і лише після вашого «ок» робить повне відео, перевіряє його та пише назву й опис.
Програмувати не потрібно. Завантажуєте й публікуєте ви завжди самі.

Усе працює на вашому комп'ютері (macOS або Windows; Linux теж підходить). Ваші відео нікуди не
передаються і ніколи не потрапляють у git.

---

## Що вміє

- **Довгі розслаблюючі відео (1–10+ годин)** з ваших кліпів: океан, дощ, ліс, камін, нічне місто,
  звуки для сну. 5 спокійних хвилин перетворюються на безшовну петлю — без помітного «стрибка»
  ні в картинці, ні в звуці.
- **Справжній польовий звук**: автоматично синхронізує окремий рекордер (Zoom, Tascam, Rode…) з відео,
  обережно прибирає гул вітру й шипіння, ставить комфортну гучність для сну.
- **«День як ніч»**: темно-синя нічна версія з денних кадрів.
- **HDR з iPhone / DJI** автоматично переводиться у звичайні кольори.
- **Спочатку короткі тести** (40–60 с, зі звуком): ви слухаєте й кажете, що не так, *до* годин рендеру.
- **Перевіряє готовий файл**: відтворення на початку, в середині й наприкінці, гучність, тривалість.
- **Shorts**: вертикальні кліпи 1080×1920 з текстом-гачком на екрані; посилання на два безкоштовні
  набори навичок для Shorts із розмовою, кулінарією та інструкціями.
- **Прибрати шум** (гавкіт, машину) на певній секунді готового відео.
- **Обкладинки** з великим текстом.
- **Назви, описи, теги, переклади, плейлисти, відкладена публікація** — заповнюються на YouTube за вас
  (після того як ви завантажите відео як «Приватне» і скажете «так»).
- **Аналітика**: що працює у вашій ніші, які відео перевершили звичайний рівень свого каналу
  («аутлаєри»), ритм публікацій каналу, план на місяць.

## Налаштування за 10 хвилин

Потрібні: **Claude Code** (обліковий запис Anthropic), **Python 3**, **ffmpeg** і **git**.

### macOS

1. Відкрийте **Термінал** (⌘ + Пробіл, введіть «Terminal», Enter).
2. Встановіть Homebrew, якщо його немає: скопіюйте команду з https://brew.sh і вставте в Термінал.
3. Встановіть програми:
   ```bash
   brew install python ffmpeg git
   ```
4. Встановіть Claude Code: https://claude.com/claude-code (застосунок або версія для термінала).
5. Завантажте проєкт і перевірте комп'ютер:
   ```bash
   cd ~
   git clone https://github.com/sasha11207/footage-to-youtube.git
   cd footage-to-youtube
   python3 scripts/doctor.py
   python3 scripts/run_demo.py
   ```
   Демо триває 3–5 хвилин і має закінчитися словами **DEMO PASSED**.

### Windows 10 / 11

1. Відкрийте **PowerShell** (Пуск → введіть «PowerShell» → Enter).
2. Встановіть програми, по одному рядку (якщо Windows питає — відповідайте «Так»):
   ```powershell
   winget install -e --id Python.Python.3.12
   winget install -e --id Gyan.FFmpeg
   winget install -e --id Git.Git
   ```
3. **Закрийте PowerShell і відкрийте знову** (щоб він побачив нові програми).
4. Встановіть Claude Code: https://claude.com/claude-code
5. Завантажте проєкт і перевірте комп'ютер:
   ```powershell
   cd $HOME
   git clone https://github.com/sasha11207/footage-to-youtube.git
   cd footage-to-youtube
   python scripts/doctor.py
   python scripts/run_demo.py
   ```
   Має закінчитися словами **DEMO PASSED**. Якщо `python` відкриває Microsoft Store — закрийте його,
   перезапустіть PowerShell і спробуйте ще раз (або встановіть Python з https://www.python.org/downloads/
   і поставте галочку «Add python.exe to PATH»).

З відеокартою NVIDIA чи Intel (використовується автоматично) і на Mac з Apple silicon рендер швидший.
Для 10-годинного відео 4K залиште 60+ ГБ вільного місця.

### Відкрийте в Claude Code

Відкрийте папку `footage-to-youtube` у Claude Code (застосунок: виберіть папку; термінал:
`cd footage-to-youtube`, потім `claude`). Claude прочитає `CLAUDE.md` і знатиме весь процес.
Пишіть будь-якою мовою — Claude відповідатиме тією мовою, якою пишете ви.

## Як просити

Скопіюйте запит, змініть частини в `<…>` і вставте в Claude Code. Claude поставить кілька
уточнювальних запитань — **по одному, з варіантами під номерами** — тож можна відповідати цифрою.

### 1. Довге атмосферне відео з моїх кадрів
> Ось моя папка `<D:/Footage/Ocean>`. Зроби 10-годинне відео нічного океану, як у цьому прикладі: `<посилання на YouTube>`. Спочатку покажи короткі тестові фрагменти.

Claude спитає: який звук брати (з камери чи рекордера), денний чи нічний вигляд, куди зберегти.
Ви отримаєте: 2–4 тестові фрагменти для прослуховування → після вашого «ок» — 10-годинне відео, перевірку шва, обкладинку і готові назву та опис.

### 2. Shorts з мого готового довгого відео
> Наріж 5 Shorts з мого відео `<D:/Videos/rain-3h.mp4>`. Напиши гачки й текст на екрані, вертикально 1080x1920.

Claude спитає: якої довжини кожен Short, які моменти вам подобаються, якою мовою текст.
Ви отримаєте: спочатку один тестовий Short, потім 5 вертикальних кліпів із текстом-гачком, плюс назву й хештеги для кожного.

### 3. Аналіз каналу
> Проаналізуй канал `<https://www.youtube.com/@SomeChannel>`: що працює, назви, тривалість, ритм публікацій.

Claude спитає: чи підключено YouTube (якщо ні — проведе вас крок за кроком).
Ви отримаєте: найкращі відео й аутлаєри каналу, які назви й тривалість виграють, як часто і в які дні виходять відео.

### 4. Аналіз ніші
> Знайди, що працює в ніші «звуки океану для сну», і склади рейтинг аутлаєрів.

Claude спитає: довгі відео чи Shorts, за який період (останній рік? 3 місяці?), яка мова/країна.
Ви отримаєте: таблицю відео, які набрали значно більше, ніж зазвичай на їхньому каналі, і 5–8 простих висновків.

### 5. Порівняти мій канал із конкурентами
> Порівняй мій канал `<посилання>` з конкурентами: `<посилання>`, `<посилання>`, `<посилання>`. Дай одну головну пораду.

Claude спитає: яка ваша мета (більше переглядів, підписників, довший час перегляду).
Ви отримаєте: коротке порівняння і **одну** найважливішу зміну на зараз, з поясненням чому.

### 6. Назви, описи, теги, переклади — і запланувати публікацію
> Я завантажив відео як «Приватне». Напиши назву, опис, теги й переклади англійською, іспанською та німецькою, постав обкладинку і заплануй на п'ятницю о 20:00.

Claude спитає: що і де ви знімали (він ніколи не вигадує фактів), ваш часовий пояс, який плейлист.
Ви отримаєте: попередній перегляд усіх змін («dry run») → після вашого «так» усе заповнюється на YouTube. Нічого не стає публічним без вашого «так».

### 7. План публікацій на місяць
> Склади план публікацій на наступний місяць на основі того, що працює в моїй ніші, і кадрів, які в мене є.

Claude спитає: скільки відео на тиждень ви реально можете робити, довгі відео, Shorts чи обидва.
Ви отримаєте: таблицю-календар — дата, тема, тривалість, чернетка назви і які ваші кліпи використати.

### 8. Виправити звук у готовому відео
> У `<D:/Videos/forest-8h.mp4>` на 2:14:37 гавкає собака. Прибери це.

Claude спитає: скільки триває шум і чи зроблене відео в цьому проєкті (тоді він виправить петлю й перезбере відео, щоб шум не повторювався).
Ви отримаєте: 20-секундний фрагмент навколо цього місця для прослуховування → після вашого «ок» — виправлений файл (картинка не змінюється).

## Підключіть свій YouTube-канал

Потрібно лише для автоматичних назв/описів/обкладинок і для аналітики. Безкоштовно. Близько
10 хвилин, один раз. Claude може провести вас крок за кроком — просто напишіть
*«допоможи підключити YouTube»*.

1. **Створіть проєкт Google Cloud.** Відкрийте https://console.cloud.google.com/ і увійдіть
   обліковим записом Google, якому належить канал. Угорі відкрийте вибір проєкту → **New project**
   (Новий проєкт) → будь-яка назва (наприклад, `my-channel-tools`) → **Create**. Переконайтеся, що
   вибрано саме новий проєкт.
2. **Увімкніть YouTube API.** Меню ☰ → **APIs & Services → Library** → знайдіть
   **YouTube Data API v3** → відкрийте → **Enable**.
3. **Екран згоди OAuth.** Меню ☰ → **APIs & Services → OAuth consent screen** (у новіших версіях:
   **Google Auth Platform**) → **Get started**. Назва застосунку — будь-яка. Email підтримки й
   контакт розробника — ваш email. Аудиторія / тип користувачів: **External**. Залиште застосунок
   у режимі **Testing**. У розділі **Test users** (або **Audience → Test users**) → **Add users** →
   ваш власний обліковий запис Google.
4. **Створіть OAuth-клієнт.** **APIs & Services → Credentials** (або **Google Auth Platform →
   Clients**) → **Create credentials → OAuth client ID** → тип застосунку **Desktop app** →
   будь-яка назва → **Create**.
5. **Завантажте JSON.** У вікні, що з'явиться, натисніть **Download JSON**. У папці
   `footage-to-youtube` створіть папку **`.secrets`** і збережіть файл туди під назвою
   **`client_secret.json`** → `footage-to-youtube/.secrets/client_secret.json`.
   (На Mac папки, що починаються з крапки, приховані у Finder: натисніть ⌘ + Shift + . щоб їх показати.)
6. **Увійдіть один раз.** Виконайте команду нижче (або попросіть Claude). Відкриється вікно браузера:
   виберіть обліковий запис каналу → якщо Google пише, що застосунок не перевірено, натисніть
   **Continue** (Продовжити) — це ваш власний застосунок → **Allow** (Дозволити).
   ```bash
   python3 scripts/yt.py auth        # Windows: python scripts/yt.py auth
   ```
   Ви побачите `signed in; channel: <ваш канал>`. Вхід збережено в `.secrets/token.json`.

**Додатково, для аналітики:** **Credentials → Create credentials → API key** → обмежте ключ
«YouTube Data API v3» → збережіть ключ одним рядком у `.secrets/api_key.txt`.

**Безкоштовна квота:** 10 000 одиниць на день на проєкт. Скільки що коштує:

| Дія | Одиниці |
|---|---|
| Оновити назву/опис/теги/переклади відео | ~50 |
| Поставити обкладинку | ~50 |
| Додати відео в плейлист | ~50 |
| Один пошук для аналітики (50 відео) | ~100 (+ ~2 за кожен проаналізований канал) |
| Список ваших відео, статистика | по 1 |

Тобто можна безкоштовно заповнювати десятки відео і робити ~50 пошуків на день.

**Безпека:**
- Папка `.secrets/` є в `.gitignore` — вона ніколи не потрапляє на GitHub.
- Ніколи не вставляйте ці ключі в чат, лист чи будь-який інший файл. Claude ніколи цього не попросить.
- Якщо здається, що ключі витекли: видаліть клієнт/ключ у Google Cloud Console і створіть новий.
- Поки застосунок у режимі «Testing», Google просить увійти знову приблизно раз на тиждень — просто
  знову виконайте `yt.py auth`.
- Як це працює: ви завантажуєте відео в YouTube Studio як **Приватне**; Claude показує пробний
  запуск (dry run) усіх змін і лише після вашого «так» надсилає їх. Інструменти ніколи самі нічого
  не публікують і не видаляють.

## Що всередині

| Шлях | Що це |
|---|---|
| `CLAUDE.md` | Як Claude працює з вами: запитання, тести, правила безпеки |
| `.claude/skills/ambient-long/` | Інструкція для довгих відео (поради зі зйомки → готове відео → метадані) |
| `.claude/skills/research/` | Аналіз конкурентів і рейтинг аутлаєрів |
| `.claude/skills/shorts/` | Shorts: вбудована вертикальна нарізка + два безкоштовні зовнішні набори |
| `scripts/doctor.py` | Перевіряє комп'ютер, показує точні кроки встановлення |
| `scripts/run_demo.py` | Самоперевірка на згенерованому кліпі |
| `scripts/footage.py` | Опис ваших кадрів, пошук дублікатів, синхронізація звуку рекордера |
| `scripts/ambient.py` | Аналіз, вибір, тест, петля, перевірка шва, збірка, перевірка, Short, виправлення звуку |
| `scripts/audioloop.py` | Чиста звукова доріжка з вибраних вручну шматків |
| `scripts/thumb.py` | Обкладинка з текстом |
| `scripts/yt.py` | Метадані YouTube (назви, описи, мови, обкладинка, плейлисти, розклад) |
| `scripts/research.py` | Аналітика YouTube (аутлаєри, перегляди на день, ритм публікацій) |
| `templates/` | Шаблони метаданих відео і профілю каналу |
| `examples/night-ocean/` | Повний приклад: 10-годинне відео нічного океану |

Папки `work/`, `output/`, `channel/`, `demo-work/` і `.secrets/` створюються на вашому комп'ютері
і ніколи не потрапляють у git.
